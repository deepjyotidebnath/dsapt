### Basic Python Stack

The easiest way is using a Python list:

```python
stack = []

# PUSH
stack.append(10)
stack.append(20)
stack.append(30)

print(stack)

# POP
print(stack.pop())

# PEEK
print(stack[-1])

# SIZE
print(len(stack))

# CHECK EMPTY
print(len(stack) == 0)
```

Output:

```text
[10, 20, 30]
30
20
3
False
```

**Important:** Stack follows **LIFO**:

```text
LIFO = Last In, First Out

10 → 20 → 30

POP → 30
POP → 20
POP → 10
```
