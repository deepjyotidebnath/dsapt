## 50 Hashing Problems — Basic to Advanced

Here is a **placement-focused Hashing roadmap**, starting from very easy problems and gradually increasing difficulty.

### 🟢 Level 1 — Basic Hashing

1. Create a dictionary and store key-value pairs
2. Search for a key in a dictionary
3. Count frequency of elements in an array
4. Find the most frequent element
5. Find the least frequent element
6. Count frequency of characters in a string
7. Find the first non-repeating character
8. Find the first repeating character
9. Check if two arrays have the same elements
10. Remove duplicate elements from an array

### 🟢 Level 2 — Easy Array Problems

11. Find duplicate elements in an array
12. Find all unique elements
13. Find the missing number using hashing
14. Find the element that appears only once
15. Find elements appearing more than once
16. Count distinct elements
17. Find common elements of two arrays
18. Find union of two arrays
19. Find intersection of two arrays
20. Check if an array contains duplicates

### 🟡 Level 3 — Hashing + Strings

21. Check if two strings are anagrams
22. Group anagrams
23. Check if two strings have the same character frequency
24. Find duplicate characters in a string
25. Find unique characters in a string
26. Find the most frequent character
27. Find the first character that appears twice
28. Check if a string contains all unique characters
29. Find common characters between two strings
30. Check if two strings are isomorphic

### 🟡 Level 4 — Hashing + Arrays

31. Two Sum
32. Find all pairs with a given sum
33. Find all pairs with a given difference
34. Find a pair whose sum is closest to X
35. Find the longest subarray with sum K
36. Count subarrays with sum K
37. Find the longest subarray with equal 0s and 1s
38. Find the longest consecutive sequence
39. Find the majority element
40. Find elements occurring more than n/3 times

### 🔴 Level 5 — Placement/Advanced

41. Find the longest substring without repeating characters
42. Find the longest substring with at most K distinct characters
43. Count distinct elements in every window of size K
44. Find the first negative number in every window
45. Find all anagram occurrences of a pattern
46. Find the smallest window containing all characters
47. Find subarrays with equal number of 0s, 1s and 2s
48. Find the number of subarrays with XOR equal to K
49. Find the longest subarray with XOR equal to K
50. Implement an LRU Cache using HashMap + Doubly Linked List

### ⭐ Most important for placements

If you don't have much time, prioritize these:

**3 → 6 → 7 → 11 → 13 → 14 → 17 → 19 → 21 → 31 → 35 → 36 → 38 → 39 → 41 → 43 → 45 → 48 → 50**

A good order for you would be:

**Frequency → Duplicates → Anagram → Intersection → Two Sum → Prefix Sum + Hashing → Sliding Window + Hashing → Advanced Hashing**.
